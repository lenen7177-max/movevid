# 复合爆款视频制作手册

把一条已经在传播的短视频，做成用户上传自己照片就能「换角复刻」的模板。

本仓库对应的产品链路：用户选模板 → 上传 1～3 张照片 → **先做素材库审核** → 通过后再把 **深度动作视频 + 提示词 + 审核通过的照片** 一起交给 Seedance（经 [APIMart](https://apimart.ai)）。成片静音；配乐在浏览器后混。

## 为什么不能把原片直接当参考视频

原片里有人脸、服装、品牌、队徽、水印。把它当作 Seedance 的 `@视频1` 会把原人物外貌带进成片，也容易触发版权和公众人物审核。

深度动作视频（灰度深度图）只保留：

- 身体动作和表演节奏
- 人物站位与互动
- 摄影机运动、构图、剪辑切点
- 场景里物体的空间关系

没有可辨认的人脸。把它当作参考视频，生成模型学的是动作和镜头，外貌由用户照片提供。

成片必须走 `reference` 模式，不能走 `edit`。`edit` 会按参考片本身改写，深度图当输入就会渲出深度图风格的成片。

## 总流程

```
找爆款原片
    → 下载并裁切（全片 ≤ 30s；精华 ≤ 15s）
    → Liblib / LibTV 生成深度动作视频
    → 把原片丢给 AI，按模板写出提示词
    → 上架：深度图 + 提示词 + 配乐 + 封面
    → 用户上传照片
    → APIMart 素材库提前审核（明星 / 公众人物 / 政治人物会被拒）
    → 审核通过后：深度图 + 提示词 + 照片 一起提交 Seedance
    → 浏览器把模板配乐混进成片
```

运营侧做前四步。产品侧在用户点生成时自动做后四步。

## 1. 选片并做成深度动作视频

### 选什么片

适合做成模板的爆款通常具备：

- 动作清楚、站位稳定，观众一眼认出「这是那条梗」
- 人数 1～3，能对应照片槽
- 时长能压进 30 秒；超过 15 秒时还能切出一条仍能认出高潮的精华
- 场景能用一句话写清（练舞室、夜场球场、公路、棚拍…）

避开：人脸特写占主导、强依赖原明星辨识度、满屏品牌/队徽、口播信息量大到离开原声就看不懂。

### 下载与裁切

1. 下载原片，只作内部制作：生成深度图、写提示词、对齐切点。站点上不要公开展示原片（深度参考视频才是发给模型的素材）。
2. 按目标画幅裁切：`9:16` / `16:9` / `3:4` / `4:3`。
3. 全片对齐到整数秒，Seedance 2.5 上限 30 秒。
4. 全长超过 15 秒时，再切一条 **精华**：≤ 15 秒，切观众认得的高潮，不要默认切开头。精华深度图、精华提示词、精华配乐必须同一段。

### 用 Liblib 出深度图

在 [Liblib](https://www.liblib.art) / LibTV 使用「深度动作捕捉」（同类方法还有 Video Depth Anything）：

1. 上传裁切后的原片。
2. 生成灰度深度视频：近处亮、远处暗的连续深度，人物是灰白剪影。
3. 导出 mp4。检查：动作完整、切点还在、没有把脸或衣服纹理带回来。
4. 全片和精华各出一条深度图，秒数必须和将要写进提示词时间轴的秒数一致。

深度图验收：

- 画面是灰度深度，不是上色原片
- 时长、画幅、切点与原片（或精华）一致
- 没有水印、字幕烧进画面（提示词也会禁止文字，但深度图本身先干净）

上传到公开媒体桶：

```
templates/<id>/reference.mp4             全片深度图，发给 Seedance（≤ 30s）
templates/<id>/reference-highlight.mp4   精华深度图（≤ 15s，有 highlightSeconds 时必做）
templates/<id>/soundtrack.m4a            从 0 秒对齐的 AAC 配乐（有授权）
templates/<id>/soundtrack-highlight.m4a  同一段精华的配乐
```

配乐不进模型。版权音乐在供应商侧会被拒；浏览器后混。

## 2. 用原片让 AI 写提示词

深度图没有颜色、没有五官、没有服装细节。场景、角色分工、表情、禁则都写在提示词里。

**不要凭记忆写时间轴。** 把原片（不是深度图）发给能看视频的 AI，让它按模板填空。切点以原片为准，写完后再用深度图核对秒数。

### 丢给 AI 的说明（复制后把原片附上）

```
根据我发给你的这段原视频，按我后面的「完整提示词模板」写一条 Seedance 复刻提示词。

要求：
1. 把模板里所有 «…» 替换成这条梗的具体内容，不要留下占位符。
2. @视频1 将来是一段灰度深度图，只提供动作、站位、运镜、切点和时间顺序；灰白剪影不是人物或道具外观。
3. 用户照片是 @图片1、@图片2…，用来锁定要换上去的人 / 动物 / 载具。按视频里实际要换的角色数写。
4. 时间轴必须对齐原视频的切点、动作起止、运动轨迹和镜头运动。多镜头就写逐镜；一镜到底就写连续时间轴。
5. 不要写歌名、歌词、歌手、球队、赛事、品牌、真人姓名。
6. 不要要求模型生成音乐、音效、台词或字幕。画面静音，口型只跟深度图节奏。
7. 点名原片轮廓里必须忽略的东西（光头、披风、球衣号码、原主角的帽子墨镜、第二辆车…）。
8. 点名这条梗最容易生成错的东西，写进【六、必须避免】。
9. 冲突时：外貌、发型、服装以照片为准；动作、镜头、时间以 @视频1 为准。
10. 超过 15 秒的片子，再另写一份精华版：时长改成精华秒数，时间轴按精华片段从 0 重计，身份锁和禁则保留。

下面是模板，请直接产出填好的提示词。
```

把附录里的完整模板接在这段说明后面。

人工复核时盯这几处：

- 秒数和深度图一致；换了深度图就重计整表
- `@视频1` 只谈动作和镜头；`@图片N` 只谈外貌
- 没有歌名、人名、队名、品牌
- 原片特有的错误轮廓已经被点名忽略
- Seedance 2.0 提示词控制在约 3600 字以内（服务端还会追加发型补充段）

本仓库的短模板走 `buildReferencePrompt`。复杂梗（多人换位、载具替换、宠物、幼儿、远景易换角）按附录全文手写，不要压进短模板。

## 3. 用户照片必须提前做素材库审核

Seedance 要真人脸通过审核，照片必须先进 **素材库（asset library）**，拿到 `asset://…` 之后才能当 `@图片N`。

明星、公众人物、政治人物的人脸会失败。只有素人、个人的人脸能过。宠物、载具槽按模板自己的规则走，同样要先审。

**必须在提交视频生成之前审完。** 生成进行到一半再告诉用户「照片不过审」，体验差，也浪费供应商时长。本仓库的实现：

1. `createVideoJob` 扣积分、把照片存进 R2，立刻把每张照片上传并提交素材库审核（`submitImageAsset` → `/v1/seedance2/private-avatar/assets`）。
2. 任务状态对外是 `processing`，阶段是 `reviewing`。
3. `syncVideoJob`（前端轮询 + 15 分钟 cron）读审核结果。任一张失败：整单失败、积分全额退回、告诉用户是哪一张被拒。
4. 全部 `completed` 且拿到 `assetUrl` 之后，才提交视频生成。阶段变为 `rendering`。

审核本身通常几秒、不按次计费。和成片无关的前置步骤（审核、描述照片发型）不计入生成成本，除非供应商开始按次收费。

产品文案要提前讲清楚：请上传自己或亲友的照片；明星、网红、政治人物的脸无法通过审核。

## 4. 把三样东西一起交给生成模型

审核通过后，一次请求里同时带上：

| 输入 | 在提示词里 | 来源 |
| --- | --- | --- |
| 深度动作视频 | `@视频1` | 模板的 `reference.mp4`（或精华） |
| 审核通过的照片 | `@图片1`、`@图片2`… | 素材库返回的 `asset://` URL，顺序与槽位一致 |
| 提示词 | 全文 | 模板 `buildPrompt(photoCount)`，再追加发型补充段 |

请求要点（见 `submitRender`）：

- `omni_reference_task_type` = `reference`（Seedance 2.5）
- `video_urls` = `[深度图 URL]`
- `image_urls` = 审核通过的照片，槽位顺序
- **不传音频**。版权音乐会被拒。
- `generate_audio` = false
- `size` = 模板画幅，`duration` = 实际渲出秒数
- 分辨率按用户选的 480p / 720p / 1080p

提交前服务端会用视觉模型给每张照片写一句发型/头饰（或动物、载具）描述，追加到提示词末尾。深度图头部轮廓是原人物的，不写这一段，成片容易长成原片发型。

失败（审核拒、内容策略、超时、供应商余额不足）一律退积分。定价按成功单算。

## 5. 定价（按模板售卖）

用户选一条模板、上传素材，按「模型 × 画质 × 时长」扣积分。供应商按生成时长计费，支付侧按积分包收款。单价、手续费、包规格放配置，用测试锁住，不要写进对外文案。

### 对外两档

默认档 = **最便宜、仍能跟上模板节奏** 的那一档。

| 档 | 角色 | 画质 | 时长 |
| --- | --- | --- | --- |
| 低价档 | 走量、获客、默认选项 | 中低分辨率 | 受模型上限约束，常要切精华 |
| 高价档 | 完整成片、高分辨率 | 含最高分辨率 | 模板全长（不超过该模型上限） |

已停售的更低价模型只保留读历史订单，不再上架。最高分辨率只挂在高价档。

同一模板的人数 / 角色 / 道具变体 **同价**：成本由时长和分辨率决定，不由槽位数量决定。

生成失败或素材被拒，积分全额退回。

本仓库对应：低价档 = `seedance-2.0-fast`（默认，最长 15s，480p / 720p）；高价档 = `seedance-2.5`（全片，最高 1080p）。

### 成本

供应商对「参考素材 + 成片」双边计时：

```
计费秒数 = 本次实际渲出秒数 × 计费倍数
成本     = 计费秒数 × 该模型该分辨率的单价
```

参考片与成片等长时，计费倍数 = 2。单价随供应商变动，只存在配置和测试夹具里。

实报金额可能略高于公式（进位、最低秒数）。积分取整时留出这截缓冲。

### 利润

常规单：扣除支付手续费后的毛利 ≥ 目标 **g = 80%**。

```
毛利 = (分摊收入 − 分摊手续费 − 生成成本) / 分摊收入
```

一笔生成为 C 成本、收 n 积分，买的是售价 P、含 F 积分、手续费 f(P) 的包：

```
分摊收入     = n / F × P
分摊手续费   = n / F × f(P)
每分最多可扛的成本 c*  =  P / F × (1 − g) − f(P) / F
```

等价：`成本 ≤ n × c*`。所有模板、模型、画质都要满足，对每一个在售包成立。手续费常见形态是比例 + 固定单笔；越便宜的包固定费占比越高，往往是最紧的约束。

连买两笔才凑齐的升级（先买小包再补差价）会付两次固定费，允许略低于 g（例如再松 1 个点），不要为它抬高所有模板标价。

用测试锁住：枚举模板 × 模型 × 画质 × 在售包，断言毛利 ≥ g。`pnpm -F @repo/app-config test` 跑这条。

### 积分怎么标

```
n = 向上取整到步长 k 的倍数
  = ceil(成本 / c* / k) × k
```

k 用 5 或 10。贴线的高分辨率再加一档步长，消化实报上浮。

低价档再加一条产品约束：

```
低价档 × 默认分辨率的积分  ≤  入门包积分数
```

入门包必须能买一条默认档。高价档全片可以贵过入门包。

短于模型上限、低价档也渲全片时，按 **实际秒数** 单独标低价档积分。切了精华的模板，低价档按精华秒数计价。

### 时长与模型

| 模板全长 L | 高价档 | 低价档 |
| --- | --- | --- |
| L ≤ T（低价档上限，常见 15s） | 全片 | 全片，按 L 计价 |
| T < L ≤ 高价档上限 | 全片 | 切一条 ≤ T 的精华，按精华秒数计价 |
| 低价档过不了审核 / 质量不可用 | 只卖高价档 | 不上架 |

精华切高潮。切掉的段落从时间轴里删掉，参考片、提示词、音轨一起换成精华版。

默认创建选项：低价档 + 默认分辨率（本仓库是 `seedance-2.0-fast` × 480p）。

### 积分包

包是收入侧，模板积分是成本侧。先定 c* 和默认档单价，再定包。

- **入门包**：刚好覆盖 1 条默认档；固定手续费占比最高，用来卡 c*。
- **中间包**：每分略降，能买 1 条高价档默认分辨率全片。
- **大包**：每分继续降，不要降到把 c* 撑破。
- **补差价升级**：24h 内从小包补到中包，价差 = 两包标价之差。
- 注册赠送等于按零收入承担生成成本，默认关掉。

### 获客例外（唯一允许低于 g 的常规单）

账号第一次买「高价档 × 默认分辨率全片」时，若标价已高于入门包，把实收积分封顶到入门包额度。

- 只作用这一档，其它画质、其它模型按标价。
- 失败退回后，名额仍在。
- 按获客成本记账，不要用它去放松 c* 或其它模板的标价。

本仓库对应 `videoConfig.firstFullCredits`（seedance-2.5 × 480p 封顶 30 分）。

### 新模板标价步骤

1. 量全长 L。L > T 则再定精华时长 H（≤ T），并确认低价档审核能过。
2. 从配置读该模型、该分辨率的单价 r，算 `成本 = 渲出秒数 × 计费倍数 × r`。
3. 用当前最紧包算出 c*，`n = ceil(成本 / c* / k) × k`。
4. 低价档默认分辨率的 n 不得超过入门包。
5. 变体不另开价。
6. 跑毛利测试；供应商改价时先改夹具里的单价，再重算所有 n。

对外文案只说积分数和大概时长，不说供应商、单价、毛利率。

## 7. 新模板核对清单

- [ ] 原片只用于出深度图和写提示词，不作为 Seedance 参考视频，也不在站点当原片播放
- [ ] 全片深度图 ≤ 30s；需要低价档时另有 ≤ 15s 的精华深度图、精华提示词、精华配乐
- [ ] 提示词由原片喂给 AI 填模板，再人工核对切点和禁则
- [ ] `depthReference: true`，任务模式是 `reference`
- [ ] 提示词不写歌名、人名、品牌；不要求模型出声
- [ ] 原片特有轮廓（发型、披风、球衣、第二辆车…）已点名忽略
- [ ] 用户照片在提交生成前走 APIMart 素材库审核；被拒立即失败并退积分
- [ ] 产品说明写清：只接受素人 / 个人人脸
- [ ] 低价档默认分辨率积分 ≤ 入门包；全矩阵毛利测试通过
- [ ] 变体同价
- [ ] 用素人照片跑通一次：审核 → 生成 → 配乐能播；用明显公众人物照片确认会在审核阶段失败

## 附录 A · 完整提示词模板

复制后替换 `«…»`。结构和禁则对齐现有复杂梗（棚拍双人、进球、追逐、吵架对口型等）。

```
【任务：按深度参考视频«逐镜 / 一镜到底»复刻«一句话描述这个梗在画面上是什么»，«角色分配：谁来自哪张图»】

@视频1 是一段灰度深度图视频，只用来提供动作、表演节奏、人物站位与互动、摄影机运动、镜头构图、剪辑切点和时间顺序。

下列时间点用于对齐，具体切点、动作起止、运动轨迹和镜头运动以@视频1 为准。
全片«主要人物只有这 N 个 / 主角只有一个»，不出现人物分身。«可选：空槽由陌生人伴舞填满，伴舞不能长得像参考图。»

【一、参考素材分工】
@视频1：只参考机位、运镜、人物站位、身体动作、«舞蹈 / 手势 / 载具轨迹 / 球的位置»、剪辑切点和时间节奏。
«@图片1：锁定«角色名»的脸、五官比例、年龄感、性别、发型发色、肤色、眼镜等面部配饰和体型。」

参考图中人物手里拿着的物品不要带入画面。«本片唯一允许的道具：…»
发生冲突时：人物外貌、发型和服装以«@图片1、@图片2…»为准；«载具外观以@图片N 为准；»动作、镜头和时间以@视频1 为准。

【二、人物一致性】
«每个角色始终是对应参考图中的同一个人。多张脸不融合、不交换、不漂移，近景和远景里那个很小的人也保持可辨认。」
表情«具体：得意 / 夸张尖叫 / 投入说唱 / 冷静射门…»，随表演自然变化，不要始终保持参考图中的静态表情。
眼镜、帽子、胡子严格跟随参考图：参考图里没有的，全片都不加。
发型严格跟随参考图，包括头发长度、卷度和颜色；头发随动作自然摆动，发根稳定，不变短、不变色、不穿过脸部。
```

### 时间轴写法

一条镜只做四件事：谁、在哪、连续动作、机位。切点从深度图读。

```
镜头0N｜ss.ss—ss.ss｜«短标题（写明在场的@图片）»
«景别/机位»。«@图片N» 在«左/中/右/前景/后景»，«从 A 动作接到 B 动作，中间过程写全»。
«道具是同一个实体：摘下的墨镜戴到另一个人脸上之后，原位置不能再多出一副。」
«深度图这一镜里的某某轮廓属于原人物，必须忽略，外观保持@图片N.»
```

### 深度图轮廓：必须点名忽略

原片剪影会进成片。提示词里点名，比只写「外观跟照片」更有效：

- 发型：光头、盘发、尖角短发、过肩长卷发
- 衣服：披风拖尾、护肩盔甲、球衣号码、绶带、原主角的帽子墨镜
- 道具：原片手里的麦、鼓棒、手机
- 载具：原片悬浮摩托 vs 用户的车

句式：

```
@视频1 中«位置»的«轮廓描述»只属于原人物，必须忽略：«角色»保持@图片N 中的«发型/衣服/载具»。
```

### 不要写进提示词

- 歌名、歌词、歌手、球队、赛事、真人姓名
- 「生成音乐 / 音效 / 台词」
- 平台水印、字幕、账号、片尾 logo
- 让模型「自由发挥」或「增加新舞步」
